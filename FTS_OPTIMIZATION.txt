FTS optimization: first measured iteration

Changes
- IK processors receive the already decoded character and category directly.
- Sorted non-overlapping IK chains use an inline array instead of a new hash table per segment.
- Already-lowercase ASCII tokens avoid the English normalizer's case-fold allocation.
- Natural-language scalar aggregates with a direct boolean MATCH predicate can use membership-only retrieval when all expression uses are boolean. Ranked/limited queries, numeric score uses, numeric thresholds, OR-only/NOT filters, boolean search, ES search and boosted search retain scoring.
- Membership-only DaaT initializes only required state, allocates its skip vector, avoids BM25 statistics, and emits a positive membership value. No persisted search result cache or benchmark-specific constants are used.

Evidence and correctness
EXPLAIN before showed calc_relevance=true even for COUNT(*) with only boolean MATCH. After shows false for eligible aggregates; ranked queries retain true.
216 IK smart/max_word document cases match the original binary, including token frequencies and long segmented inputs. Extended corpus: 324 IK/BENG cases passed. Official tokenize_function mysqltest passed unchanged. 234 aggregate/score/ranking/threshold/update/delete/transaction queries matched the scoring reference. Regression scripts are in unittest/storage/fts and use separate local test databases.
