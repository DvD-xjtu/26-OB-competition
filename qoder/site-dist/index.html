实验续航是一个面向科研过程的中文工作台。研究任务、实验观察、关键决策、 下一步待办与原始资料链接，全部通过 真实 PowerContext HTTP API 保存；刷新页面、重启应用或开启新会话后， 研究上下文仍然可以被重新读取、检索和交接。

真实 HTTP API 一任务一 Scope Memory + Source 引用 无本地降级
查看本地运行方式 查看验证记录

※ 这是静态项目展示页。 本页不包含在线后端，也不提供可交互的托管演示。要读取或写入研究数据， 需要在本地启动 Node 应用并连接同机运行的 PowerContext。

设计原则：研究数据只存在于 PowerContext，应用目录内没有研究数据副本。

storage.mode = "powercontext-http" · localFallback = false

不是聊天记录，
是可交接的研究状态。

研究过程经常在“实验做完”和“下次继续”之间断裂。实验续航把进展拆成四类可检索记录， 在交接时附上 Memory 引用与 Source 证据，让下一次实验从可核验的来源继续，而不是依赖回忆。

观察

记录实验现象

测量值、异常、环境条件与重复次数写入 Memory，之后可被全文检索。

决策

留下取舍依据

为什么暂停、为什么换方案、影响范围是什么，交接时可以逐条复核。

待办

写成下一步动作

把“继续研究”拆成可执行动作，新会话打开后可以直接接着做。

链接带来源证据

链接先写入 Memory，再以 Source 保存；摘要同时列出 Source ID 与摘要值。

真实 PowerContext，
不是模拟后端。

主流程不经过本地 JSON 或 mock 服务：任务来自 Scope 列表，记录写入 Memory， 链接额外写入 Source，搜索调用 PowerContext 检索，交接读取 Memory、Sources 与准备上下文。

应用实际调用的接口

Scope GET /v1/scopes · POST /v1/scopes · GET /v1/scopes/{id}
Memory POST /v1/memory/remember · POST /v1/memory/entries/list
检索 POST /v1/memory/search
Source POST /v1/sources/content · GET /v1/scopes/{id}/sources
上下文 POST /v1/context/prepare

故障时就失败，不悄悄降级

PowerContext 不可达时，界面显示离线状态并禁用写入；API 返回 503 powercontext_unavailable，错误详情明确声明 noLocalFallback: true。应用不会在本地生成一份“看起来还在工作”的数据副本。

!

隔离边界

每个研究任务对应一个 Scope。应用在每个任务请求中校验标题前缀， 拒绝访问不属于实验续航的 Scope。Scope 是数据分区键，不替代多租户鉴权。

在本地运行它。

应用与 PowerContext 都运行在你的机器上。Node 服务只代理请求， 浏览器不会接触 PowerContext Bearer 令牌；研究数据也不会写入应用目录。

准备 PowerContext

使用 Python 3.11+；若 3.14 缺少兼容 wheel，请改用 3.12 或 3.13。

python -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements-powercontext.txt

启动真实服务

默认端点为 http://127.0.0.1:8000。保持该进程运行。

powercontext server run
curl --fail http://127.0.0.1:8000/health/live

配置实验续航

复制示例配置；不要把真实令牌提交到仓库。

cp .env.example .env
# POWERCONTEXT_URL=http://127.0.0.1:8000
# POWERCONTEXT_TOKEN=  # 可选

启动本地界面

零第三方 npm 运行时依赖。打开终端提示的本地地址。

npm ci
npm start
# http://127.0.0.1:4173

注意：本页只解释项目与本地运行方式，不提供在线 API。 如果你的 localhost:8000 没有运行 PowerContext，应用会明确显示离线并拒绝写入， 不会切换到本地模拟数据。完整的测试命令、安全说明与限制见仓库中的 README.md 与 DEVELOPMENT.md。
